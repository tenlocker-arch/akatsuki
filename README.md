# アカツキ競馬 — 穴狙い・帯封特化の競馬予想エンジン

「うまい予想屋」がやることをコードにしたツールです。
一頭一頭について、取れる情報を取れるだけ取ってきて——前走・前々走で何が起きたか、
なぜ負けたか、今回は何が変わるのか、どんな脚質の馬にどの騎手が乗るからどんな展開になるのか——
を**出典付きのストーリー**に組み立て、過小評価された穴馬を軸に**帯封(配当100万円超)を狙う買い目**まで出します。

## 何をするか

1. **データ収集** — netkeiba の出馬表と全頭の戦績ページを取得(またはJSON/同梱サンプル)
2. **脚質判定** — 通過順から逃げ/先行/差し/追込を判定
3. **展開シミュレーション** — 逃げ・先行勢の数からペースを予測し、脚質ごとの展開利を算出
4. **敗因エクスキューズ検出** — 近走の負けから「度外視できる言い訳」をデータで拾う
   - ハイペースを前で受けて失速 / スロー前残りを豪脚で追うも届かず(展開負け)
   - 格上挑戦で相手が強すぎた / 出遅れ・不利の記録 / 道悪・距離不適
   - 馬体重激変 / 休み明け
5. **条件好転の検出** — 騎手強化・コース巧者・斤量減・道悪巧者など今回のプラス材料
6. **能力推定と穴度算出** — 「実力順位と人気順位の乖離」+「言い訳」+「好転材料」+「展開利」
7. **ストーリー生成** — 上記すべてを、根拠(どのレースのどのデータか)を添えた読み物に
8. **買い目構築** — ☆穴馬を1着固定した三連単フォーメーション(帯狙い本線)+
   穴2着付け・三連複・ワイド保険。予算を 6:3:1 で配分

すべての所見は必ず出典(レース名・日付・通過順・ペースなどの生データ)を持ちます。

## 使い方

```bash
pip install -r requirements.txt

# まずは同梱サンプルレースで試す(ネット不要)
python -m keiba demo

# netkeiba のレースIDを指定して予想(日本国内のネットワークから実行すること)
python -m keiba predict --race-id 202506030811 --budget 20000

# 自分で用意したJSONから予想
python -m keiba predict --json data/myrace.json
```

ターミナルに要約が出力され、`reports/<race_id>.html` に詳細レポート
(展開予測・穴度ランキング・一頭ずつのストーリー・買い目)が生成されます。

レースIDは netkeiba の出馬表URL `https://race.netkeiba.com/race/shutuba.html?race_id=202506030811`
の `race_id=` 以降の数字です。

## JSON入力フォーマット

`data/sample_race.json` がそのままリファレンスです。`race` の下にレース条件と
`entries`(各馬の馬番・騎手・オッズ・人気と `past_races` の配列)を書きます。
過去走には通過順 `passing`、レースのテン/上がり3F `pace`、自身の上がり `agari`、
着差(秒)`margin_sec` を入れるほど分析が深くなります。

## カスタマイズ

- **騎手ランク**: `keiba/analyzer.py` の `JOCKEY_TIERS`(S/A の静的テーブル)を編集
- **クラスの格**: 同 `CLASS_VALUES`
- **展開利の重み**: 同 `PACE_ADVANTAGE`
- **買い目の予算配分**: `keiba/bets.py` の `_allocate_budget`(三連単6割/三連複3割/ワイド1割)

## 注意事項

- 本ツールはヒューリスティックな予想であり、**的中・回収を一切保証しません**。
  想定配当は単勝オッズ積からの粗い概算です。馬券は20歳以上・余裕資金で。
- netkeiba は日本国外のIPをブロックすることがあります(403)。スクレイプは
  リクエスト間に1秒のウェイトを入れ、`.cache/` にキャッシュして再アクセスを
  最小化していますが、節度を持って利用してください。
- ページ構造の変更でスクレイパーが壊れた場合は、JSON入力モードが逃げ道になります。
