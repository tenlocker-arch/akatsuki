# AIと考える教室 — 構想ドキュメント

最終更新: 2026-06-13

---

## 1. ビジョン(なぜやるのか)

自分の子供とその世代が、20年後の社会で「豊かに生きていける力」を、教育という形の資産として残す。

- 20年後、ライフスタイルもビジネススタイルも現在の価値観とは別物になっている可能性が高い
- 将来、直接の対面以外の人間同士のやり取りの多くにAIが介在すると予想する
- そのときに価値を持つのは、AIの操作知識ではなく、**AIを介してより深く考えられる力**

> 教室の憲法となる一文:
> **「介在するAIに思考を委ねるのではなく、AIを介してより深く考えられる人間を育てる」**

## 2. コンセプト

### 「AIを学ぶ」ではなく「AIと考える」

- 英会話教室のネイティブ講師と同じで、AIは「教える対象」ではなく「対話相手・環境」
- 「AIリテラシー教室なのにAIの使い方を教えない」のは矛盾ではなく、コンセプトの核心

### AIは「思考を映す鏡」

- 曖昧な問いには曖昧な答えしか返らない。問いの質が出力の質に直結する
- 言語化できなければ意図が伝わらず、伝わらなさが即座に可視化される
- 人間の先生は「察して」補完するが、AIは察しない。思考力がむき出しで試される

### 伸ばす力(非認知能力)

問いを立てる力 / 言語化能力 / 構造理解 / 批判的思考(出力を疑う力) / パラレルシンキング / 哲学的対話

### 差別化の一文

**「プロンプトのテクニックは2年で陳腐化するが、問いを立てて言語化する力は陳腐化しない」**

### カリキュラムの共通骨格(大人・子供共通)

```
問いを立てる → AIと対話する → 出力を疑う → 自分の言葉で再構築する
```

題材を変えるだけで両層に使える。教材開発は二重にならない。

## 3. 二層構造 — 「大人で稼ぎ、子供で志を果たす」

| | 大人向け | 子供向け |
|---|---|---|
| 役割 | キャッシュエンジン(初年度の主力) | ミッション・長期ブランド |
| 顧客構造 | 財布と受益者が同一。痛みが具体的で緊急 | 受益者(子供)と支払者(親)が別。説得が二段階 |
| 単価感 | 講座数千円〜数万円、法人研修1本10〜30万円 | 月謝6,000〜8,000円 |
| 競合 | ツール研修はレッドオーシャン。ただし「問い・言語化」の切り口は空いている | 非認知能力系AI教育はほぼ空白 |

- 大人向けの切り口: **「AIで成果が出る人と出ない人の差は、ツールの知識ではなく思考の言語化である」**(プロンプト研修を受けたのに成果が出ない層の"次の悩み"を突く)
- 二層のブリッジ: **大人向け講座の受講者の相当数は親**。「この思考法、うちの子にこそ」という動線が自然に発生する

### 自分への憲法

> **大人向け売上の比率がどうなっても、子供向けクラスを月1回は必ず開催する。**

(大人市場の引力で「法人研修業者」に漂流するのを防ぐ。個人事業の最大の資本はモチベーションであり、その源泉は子供側にある)

## 4. 制約とリスク3原則

制約: 個人の活動。組織的スタートではない。隔週土曜のレンタルスペース開催や、Zoomでの個別契約が現実的な形態。**赤字イベントが2〜3回続いたら継続不能。**

よって「客が集まらず赤字」という事象自体が起こらない構造を最初に作る:

1. **固定費ゼロ** — スペースは申込確定後に時間貸しで予約(無料キャンセル期限のある所を選ぶ)
2. **最低催行人数+事前決済** — 「6名で開催、未達なら中止・全額返金」を明記。赤字の最大値を常にゼロ円にする
3. **先に売って、後に作る** — 箱を借りてから集客するのではなく、申込が集まったら箱を借りる

## 5. ロードマップ(二層構造版)

### Step 1: 大人向けZoomモニター(0〜1ヶ月目)

- 無料〜1,000円、Zoom開催(費用ゼロ)、知人・SNSから2〜6名
- 目的: カリキュラム骨格の検証、受講者の声の収集、自分の手応え確認
- 大人から始める理由: 集めやすい(子供を預けてもらうには信頼の壁がある)、フィードバックが言語的で改善が速い、受講者がそのまま子供向けの見込み親になる

### Step 2: 大人向け単発有料講座(1〜3ヶ月目)

- Zoom、3,000〜5,000円、90〜120分、月1〜2回。最低催行+事前決済
- 「看板講座」を1本磨き上げる(毎回新作を作らない)
- 並行してnote等で発信開始(講座1回ごとに記事ネタが生まれる)

### Step 3: 子供向け無料モニター(2〜4ヶ月目、Step 2と並行)

- 知人の子供2〜4人、自宅・公民館(数百円〜千円台)
- 目的: 子供向けファシリテーションの検証、「どこで食いつき、どこで飽きるか」の把握、保護者の声と写真(集客素材)の収集

### Step 4: 親向けセミナー+子供向け単発ワークショップ(3〜6ヶ月目)

- 親向け「子供にAIをどう与えるか」セミナー(無料〜1,000円、Zoom)→ 子供向けワークショップ(2,000〜3,000円、最低催行方式)への動線
- 大人向け講座の受講者(=親)にも案内

### Step 5: 継続化・三本柱(6ヶ月目〜)

- 大人向け: 単発→連続コース(例: 4回×2〜3万円)、スモールB2B営業開始(中小企業・士業・個人事業主のニッチから)
- 子供向け: 単発リピーターを月謝制(隔週土曜、月6,000〜8,000円)へ転換。転換率を必ず記録する
- Zoom個別(子供・大人とも)を高単価で並行

### 食べていける規模の構成イメージ(1〜2年目)

| 柱 | 構成例 | 月額 |
|---|---|---|
| 対面クラス(子供) | 3クラス×6人×8,000円 | 約14.4万 |
| オンライン個別 | 5人×12,000円 | 6万 |
| B2B(研修・出張授業・講演) | 月2本×5万円〜 | 10万〜 |

- 一本柱で30万を作ろうとすると生徒40人近く必要になり個人運営は破綻する。三本柱の合算で組む
- B2B(学童、塾、私立小、PTA、中小企業研修)は単価が高く集客リスクが先方持ち。制約に最も適合する収益源
- 最大のボトルネックは「最初の他人の6人」。発信と親向け・大人向けセミナーで信頼を積む以外に近道はない

## 6. 講座コンテンツ案

### 大人向け看板講座(90分)

タイトル案: **「AIで成果が出る人と出ない人の差 — プロンプトではなく『問い』の話」**

| 時間 | パート | 内容 |
|---|---|---|
| 15分 | 冒頭デモ | 同じ業務課題を「曖昧な依頼」と「構造化された依頼」でAIに投げ、出力の差を見せる。差の正体はプロンプトの長さではなく思考の解像度だと示す |
| 20分 | ワーク1: 言語化 | 自分の実業務の課題を1つ選び「誰が・何を・なぜ・どうなれば成功か」に分解して書く → AIに投げる |
| 20分 | ワーク2: 疑う | AIの回答に対し「この前提は正しいか」「何が抜けているか」を3つ挙げて問い直す |
| 20分 | ワーク3: 再構築 | 最終的な答えを「同僚に説明するつもりで」自分の言葉に要約する |
| 15分 | 振り返り | 今日の構造そのものが明日から使える思考テンプレートであることを示す |

ポイント: 受講者が**自分の実課題**を持ち込む設計にする。汎用サンプルより満足度と口コミが段違いになる。

### 子供向けワークショップ(小3〜小6、90分)

構成: つかみ(AIと遊ぶ)→ 問いを定義する → AIと対話 → ツッコミタイム → 自分の言葉で発表

テーマ案:

1. **「AIに『さいきょうの遠足プラン』を作らせよう」** — まず「さいきょうって何?」をみんなで定義(哲学対話)→ AIに依頼 → 出てきたプランの変な所探し(批判的思考)→ 修正依頼 → 発表
2. **「AIはウソをつく?」** — AIが間違えやすい質問を投げて、本当かどうか自分たちで調べる。情報の疑い方を学ぶ
3. **「質問だけで答えにたどりつくゲーム」** — 問いを立てる力そのものをゲーム化

ポイント: 最後の「自分の言葉で発表」が非認知能力の成果であり、**迎えに来た親が目撃する成果**でもある(継続率に直結)。

### 親向けセミナー(60〜90分、無料〜1,000円)

タイトル案: **「子供にAIをどう与えるか — 禁止でも放任でもない第三の選択肢」**

1. AIネイティブ世代が生きる前提の変化
2. 「禁止」の弊害と「放任」のリスク
3. 鍵は操作方法ではなくリテラシー(問いを立てる力・言語化)
4. 家庭で今日からできる3つの習慣
5. (最後に)教室の案内

## 7. KPI(各Stepで必ず記録する数字)

- モニター/単発の申込数・参加数・満足度(NPS的な一問でよい)
- 親向け・大人向けセミナー → 子供向け/継続講座への転換率
- 単発 → 月謝制への転換率(事業の生命線)
- 発信(note等)の経由申込数

## 8. 未決事項

- 屋号・教室名
- 対象学年の最終決定(まずは小3〜小6を仮置き)
- 使用AIツールと子供のアカウント・安全面の設計(保護者同意、講師アカウントの画面共有方式など)
- 価格の最終決定(モニターの反応を見て調整)
